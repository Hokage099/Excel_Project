# Excel_Project

📊 Jotstar OTT Platform Dashboard

This project is an Excel-based interactive dashboard created using Pivot Tables and Pivot Charts to analyze user behavior, content performance, and subscription trends on the Jotstar OTT platform.

🔑 Key Data Sources

Subscribers Data (Jotstar_subscribers)

User demographics (age group, city tier)

Subscription details (plan type: Free, Premium, VIP)

Revenue from paid users

Subscription start/change dates

Content Data (Jotstar_Contents)

Content metadata (ID, type, language, genre)

Runtime analysis

Total number of contents (~2360)

Average content duration (~90 mins)

Content Consumption (Jotstar_Content_consumption)

User watch time (in minutes)

Device type distribution (Mobile, Laptop, TV)

Total users (~44,620)

Total watch time (~941M minutes)

📈 Dashboard Insights

Subscribers Overview

Total Users: ~44,620

Paid Users: ~32,524

Revenue tracked from subscription plans (Premium, VIP).

Content Insights

Library size: ~2360 titles

Most common runtime: ~90 minutes

Wide variety of languages & genres.

Consumption Patterns

Majority of users watch via Mobile.

Total watch time: 941 million minutes.

Device-level segmentation available.

🛠️ Features of the Dashboard

Interactive filtering by age group, city tier, and subscription type.

Pivot tables to analyze user distribution, revenue, and plan churn.

Pivot charts to visualize content genres, language spread, and watch time trends.

Automated calculations for KPIs like total users, paid users, revenue, and average runtime.
